\# FOREST TREASURE



A Third-Person 3D Exploration Game



\## About the Project



FOREST TREASURE is a small 3D exploration game developed with Unity 6.5.



Players explore a mysterious forest, collect five magical crystals, discover a golden key, and unlock an ancient portal to complete their adventure.



This project was created as a practical learning experience to explore Unity's core development features and gameplay systems.



\## Gameplay Features



\- Third-person character movement and jumping

\- Camera follow and mouse-controlled rotation

\- Crystal collection system

\- Golden key interaction

\- Treasure chest animation and interaction

\- Portal unlocking system

\- Particle effects and glowing materials

\- Environmental audio and interaction sound effects

\- Quest objective UI

\- Main menu and pause menu

\- Victory and restart systems



\## Controls



| Key | Action |

|---|---|

| WASD | Move |

| Mouse | Camera control |

| Space | Jump |

| E | Interact / Collect |

| Esc | Pause / Resume |



\## Built With



\- Unity 6.5

\- C#

\- Universal Render Pipeline (URP)

\- TextMeshPro

\- Unity Input System

\- Unity Animator

\- Unity Particle System



\## Development



This project was developed as an individual learning project, with a focus on understanding Unity workflows, C# scripting, gameplay logic, UI systems, and scene management.
